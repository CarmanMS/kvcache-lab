# 开源前审查记录

日期：2026-10-26。版本：本地 v0.1，尚未提交或发布。

三名独立审查代理分别负责数值与缓存、课堂交互、许可证与工程发布；修复后再次复验。审查不等于生产级稳定性保证。

## 发现与处理

| 领域       | 首轮发现                                      | 处理                                                              |
| ---------- | --------------------------------------------- | ----------------------------------------------------------------- |
| 许可       | 缺许可证                                      | 添加 MIT、来源声明、贡献及安全说明                                |
| 输入       | 重绘丢失草稿和展开状态；超过16个token静默截断 | 独立保存草稿，保留全文并显式拒绝超限提交                          |
| 课堂操作   | 焦点、选区、内部滚动重置；提交丢失输入焦点    | 保存恢复交互状态，选中对象越界时自动揭示                          |
| 可读性     | 关键字号小、文字对比度不足、8-head拥挤        | 调整字号、对比度、数值底色和布局；增加可访问标签                  |
| 公式验证   | 两条计算路径共用算子，不能发现共同错误        | 添加独立标量参考；移除scaling或RoPE的变异实验均触发失败           |
| 比较函数   | 形状不一致或非有限数可能被错误判等            | 严格验证形状、元素与有限性                                        |
| 快照       | 可变成员与池内数据共享引用                    | 深复制并增加独立性回归检查                                        |
| 地址稳定   | 部分页补齐后合并迁移                          | 只在页边界匹配已知整页，既有部分页不迁移；按实际映射高亮共享token |
| 参数       | 部分非法TP、主机数和容量输入未被拒绝          | 在导出API边界验证                                                 |
| 开发服务器 | 符号链接可能绕过资源边界；Host未约束          | 白名单、realpath边界、GET/HEAD及本机Host验证                      |
| 构建       | 旧dist可能保留已删除资源                      | 清理旧产物，拒绝源码符号链接，安全替换输出链接                    |
| 工程       | 缺格式门禁、HTTP回归与跨平台CI                | 锁定开发依赖，添加检查和Node22/24三平台CI                         |
| 可追溯性   | 模型配置引用浮动main                          | 锁定Qwen配置修订，在源码、页面和文档使用                          |
| 模块边界   | 页面、状态和事件过度集中                      | 拆分controller、views与DOM生命周期，补充架构文档                  |

## 验证

- 自动检查：语法、Prettier、数值/模型/页池/控制器/DOM/HTTP/构建回归，以及静态构建。
- 数值覆盖独立算子参考、增量/全量等价、历史KV不变、TP部分和、容量公式。
- 浏览器复验覆盖桌面与390px：草稿、展开状态、播放期间输入选区、提交焦点、长输入提示、图内滚动、对象联动及8-head布局。
- 抽查四类关键文字对比度为5.14、5.30、5.47、5.18；这不是整站WCAG认证。
- 安装依赖时npm audit返回0漏洞；这仅代表当时依赖公告状态。
- 工程发布复验通过；交互末轮新增跨视图可见性问题已修复，390px下选中head完整位于画布内的定向复验通过。
- 最终浏览器操作链通过：三种架构的4层8Q、单步与撤销、TP8两机8卡、完整前缀共享4token、相同后缀共享0且深层K不同、模型身份隔离、请求结束与淘汰，以及播放结束；未出现NaN或异常。

最后发现的390px、4层MHA8、16token组合曾有7px横向溢出；已用受限网格列和min-width修复。随后真实浏览器定向复验确认clientWidth与scrollWidth均为390，页面无横向溢出，控制台无错误。

## 发布边界

当前是经过审查的早期教学版本，不称为成熟稳定版本。实际运行验证在macOS完成；Windows/Linux及Node24尚待CI实际执行。未进行长期课堂使用、完整辅助技术审计或真实性能验证。

模型是确定性教学Transformer，页池和设备是明确约定的模拟；没有运行真实SGLang或真实多机通信。MoE、MLA、KDA仍属后续范围。已建立[私有验证仓库](https://github.com/CarmanMS/kvcache-lab)，尚未公开发布，实际CI结果另行记录。
