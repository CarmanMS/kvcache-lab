# 结构与计算边界

KVCache Lab 是浏览器内的教学实验室。数值模型、页分配器和设备布局共同支撑可探索的视图；它不连接真实推理服务。

## 模块边界

| 模块                 | 职责                                                          |
| -------------------- | ------------------------------------------------------------- |
| `src/math.js`        | 纯数学算子、确定性权重、严格张量比较                          |
| `src/model.js`       | 因果 Transformer、增量/完整前缀执行、各层与各 head 的计算快照 |
| `src/cache.js`       | 独立页池、完整前缀匹配、引用/淘汰、设备归属与容量估算         |
| `src/controller.js`  | 实验状态、输入校验、运行操作、撤销与有界计算缓存              |
| `src/views.js`       | 将当前状态和计算结果转换为视图，不驱动计算步骤                |
| `src/app.js`         | DOM 事件、播放生命周期、焦点/草稿/滚动保持                    |
| `scripts/assets.mjs` | 构建和服务器共同使用的公共资源白名单                          |
| `scripts/server.mjs` | 可测试的本机静态 HTTP 服务                                    |
| `scripts/build.mjs`  | 干净、可重复的静态产物构建                                    |

内部 JavaScript 导出方便自动验证和后续扩展，当前不承诺稳定的公共 SDK 接口。

## 数值执行

默认小模型为 3 层、4 Q heads、2 KV heads、每 head 4 维，残差宽度 8。它使用固定种子的未训练权重；输入 token 采用公开说明的教学分词，续写 token 是预设序列。

每层执行 pre-norm、Q/K/V 投影、Q/K head normalization、RoPE、因果 attention、输出投影与残差、SwiGLU FFN 与残差。缓存保存已处理的 K 和 V。页面可查看历史 Q 的调试快照，但这些快照不是模型的持久 KVCache。

浏览器为了回看任意位置会重建教学数值，不把重建时间当作推理性能。增量路径与完整前缀路径共享基础算子，因此测试既检查两者等价，也通过独立二维标量参考验证关键公式，避免两条路径“同错”。

## 页池

请求的完整 token 前缀和模型身份决定能否复用。在页边界，本次操作已知完整页时，分配器先查找已有匹配页，命中后直接复用。已分配的部分页在后续补齐时保持原地址，不进行事后去重。

因此，逐 token 处理与一次处理完整前缀可以得到相同数学输出，却有不同的页复用结果。共享页的位置也不一定从 t0 连续开始，页面按真实槽位映射逐位置高亮。

请求结束只移除活动引用；页可继续保留给兼容前缀。淘汰只回收无活动引用页。数值快照仍可回看；被回收的物理缓存会明确标注为不再驻留。快照和撤销检查点均隔离可变数组。

这是确定性教学分配器，不声称重现某个 SGLang 版本的所有调度、分页或复用细节。

## 多卡与容量

TP 以 Q heads 分片，各 rank 持有所需的 KV heads；TP 超过 KV head 数时会显示复制。各 rank 的输出投影部分和在数学上实际归并。机器容器只表达部署关系，没有真实 GPU 执行或网络传输。

容量估算使用精确字节换算，但不包括页之外的元数据、权重、临时工作区和量化 scale。BF16/FP8 选项只改变容量模型，数值运算仍是浏览器浮点。

Qwen3-32B 参数固定到 [config revision 9216db5](https://huggingface.co/Qwen/Qwen3-32B/blob/9216db5781bf21249d130ec9da846c4624c16137/config.json)，核对日期 2026-10-26：64 层、64 Q heads、8 KV heads、head_dim 128、hidden_size 5120。BF16 每逻辑 token 全模型 KV 为 256 KiB，32,768 token 为 8 GiB。

## 界面状态

教师自行组织讲授。视图按模型、设备、请求缓存组织，没有固定问答入口。编辑草稿和展开状态独立于模型运行；撤销模拟操作不覆盖正在编辑的草稿。重绘保存输入光标与滚动，直接选择对象时将选中对象保持在画布内。

输入超过 16 个教学 token 或 160 个字符时明确报错，保留完整输入和原实验，不截断文本。

## 验证与扩展

测试分为数学参考、模型不变量、页池生命周期、控制器、DOM 交互、HTTP 与构建。CI 在 Node 22/24 与 Linux/Windows/macOS 上配置运行；界面布局仍需真实浏览器验收，DOM 测试不证明视觉质量。

后续架构需要不同类型的 trace 与存储：MoE 的路由/专家、MLA 的压缩状态和 KDA 的递归状态不会混用同一个普通 KV 存储公式。当前可选架构仅为已实现的 MHA/GQA/MQA。
